## 2. Arzenál kofeinu

Pro programování a učení do pozdních hodin používám osvědčené nástroje. Zde je ukázka mého oblíbeného pomocníka v Pythonu, který mi počítá vypité šálky kávy:

```python
def spocti_kavu(salky):
    kofein_mg = salky * 95
    if kofein_mg > 400:
        return "Pozor, srdce ti buší jako o bonga!"
    return "Jsi v bezpečí, pokračuj v kódu."

print(spocti_kavu(3))
